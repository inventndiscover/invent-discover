GLB → Three.js Studio

Open a 3D model, spin it around, see what makes it heavy, and take it to the web: ready-to-paste Three.js code, a single web page you can share, or a clean .glb.

Built on three.js, the open-source 3D library by Ricardo Cabello (mrdoob) and contributors. Credits

🔒

Your model never leaves your device. The studio runs entirely in your browser: nothing is uploaded to Invent + Discover or anywhere else, and nothing is stored online. Only use models you made or have the right to use.

How heavy is it for the web?
    Take it to the web

    A complete page that loads your model with lights, orbit controls and animation. Save it as index.html and put model.glb in the same folder. Run it from a local server or any web host (opening the file directly won't load the model).

    
      
    
    
    
    
    
      
    One .html file with your model packed inside. Double-click it to open in any browser, send it to a friend, or upload it anywhere. It loads three.js from a public CDN, so it needs an internet connection.
    
      
    
    
    
    
    
      
    One self-contained .glb, the format the web, Meta Quest and most AR tools prefer. Useful for turning .fbx, .obj, .stl or multi-file .gltf models into a single file.
    
      
    
    
    
    
    
      
    For React projects using @react-three/fiber and @react-three/drei. Put the .glb in your public folder.
    
      
    
      
    
    
    
  
    

  
    
    
    Credits and good to know
    
    
    This studio is built on three.js (MIT licence), created by Ricardo Cabello (mrdoob) and maintained by its open-source contributors, including the loaders for glTF, FBX, OBJ and STL and the glTF exporter. Compressed models are opened with Google's Draco decoder and the meshoptimizer decoder by Arseny Kapoulkine. The glTF format itself is a standard from the Khronos Group.
    
    
      
      
    • Working files from Blender (.blend), 3ds Max, Cinema 4D or Maya can't be opened here: export them as .glb or .fbx first.
      • 
      
    • Converting keeps shapes, materials, textures and most animations, but some effects specific to one app may not carry over.
      • 
      
    • The studio needs a browser with WebGL, which almost every modern phone and laptop has.
