## Everything else

Bridge, toll plaza, city, sea, sky, signs, number plates, sounds (engine, wind, sea,
beeps) and the UI are generated in code for this page. The scene is a digital,
illustrative creation inspired by the Bandra–Worli Sea Link; it is not a surveyed map.

Attribution is shown on the page under "Credits & licences" in the controls, and in
short on the opening notice. Licences were read from each file's Sketchfab licence
file and page (12 Nov 2026).
